# Campaign register route evidence

**Scope:** Read/list evidence only for inventory routes AL-0075, AL-0601, and AL-0023. Route IDs and status come from the [route inventory CSV](COMMAND_OS_ROUTE_INVENTORY.csv), which remains the inventory source of truth. The three rows are all `NOT_STARTED` for React migration. This sheet does not map create, edit, send, disable, or other state-changing route semantics; those links and actions are separate higher-risk workflows.

## Blade and browser implementation evidence

- [Campaign register Blade template](../../apps/api/resources/views/console/campaigns/index.blade.php#L1) renders a server-side table. Its header contains 14 columns: selection, campaign, ISP, offer, server, total send, fraction IP, sleep email, sleep IP, seed, send type, actions, progress, and send. The table has a 1360px minimum width inside a responsive overflow wrapper ([table markup](../../apps/api/resources/views/console/campaigns/index.blade.php#L94), [column styles](../../apps/api/resources/views/console/campaigns/index.blade.php#L327)).
- Filters include the disabled toggle, 20/50/100 page size, active-send view, date range, and search; filter forms preserve applicable query parameters ([toolbar and forms](../../apps/api/resources/views/console/campaigns/index.blade.php#L10), [filter controls](../../apps/api/resources/views/console/campaigns/index.blade.php#L43)). [campaign-register-controls.js](../../apps/api/public/console-assets/campaign-register-controls.js#L1) clears search and submits the GET filter form. [analytics-date-range.js](../../apps/api/resources/views/console/campaigns/index.blade.php#L360) initializes the date selector.
- Rows include register values from the latest saved revision, view/log links and other row controls. The page also renders send/snapshot progress regions and polls the corresponding GET progress URLs ([row details](../../apps/api/resources/views/console/campaigns/index.blade.php#L122), [progress markup](../../apps/api/resources/views/console/campaigns/index.blade.php#L179), [polling script](../../apps/api/resources/views/console/campaigns/index.blade.php#L551)). Those adjacent actions are recorded here as visible affordances only; their business semantics are out of scope for this read/list sheet.
- The inventory records this family as Laravel Blade/page JavaScript. No React implementation evidence was found for these three route rows.

## Sampled production observation

A read-only screenshot and accessibility-tree inspection of `/mailer/campaigns` in the current turn observed search and date filters, row pagination, a disabled toggle, bulk and per-row controls, send/progress state, 12+ visible columns, and horizontal scrolling at 1280×720. No controls or actions were activated. The screenshot was inspected in CUA but is not available as a local path, so no screenshot/viewport artifact is retained here. No campaign/client names, record counts, or server hostnames are recorded. This is a sampled production observation, not evidence that all rows, roles, viewport sizes, or workflows behave identically.

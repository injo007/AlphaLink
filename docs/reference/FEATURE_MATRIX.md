Status describes **parity progress**, not whether DMS source mentions a feature. Reference paths below are from prior read-only source snapshots, not freshly mounted code. E-numbers resolve in `EVIDENCE_REGISTER.md`. A row can become `PARITY_CONFIRMED` only after the acceptance record in `AGENTS.md` is complete and its test results are recorded.

# Archived AlphaLink engineering evidence

The files in this directory preserve dated research, historical workflow comparisons, static captures, verification notes, and implementation history. They are not current product identity, live system state, authorization, or operating instructions.

Use [the current master specification](../ALPHALINK_MASTER_SPEC.md) and [current progress](../ALPHALINK_PROGRESS.md) for AlphaLink requirements and status. Keep old migration-ledger names and import markers only where needed to upgrade existing AlphaLink data safely; do not treat archived terminology as runtime naming guidance.

Historical records remain unchanged where their exact source paths, hashes, observations, and caveats are needed for traceability. The detailed development log is at [ALPHALINK_DEVELOPMENT_HISTORY.md](ALPHALINK_DEVELOPMENT_HISTORY.md).
